# Support / Unterstützung

GunGame AMXX 3++ — pur3gaming Edition

[English](#english) | [Deutsch](#deutsch)

## English

### 1. Supported versions

Support is available for the current GunGame AMXX 3++ development version and current releases, including the current release candidate. The original GunGame AMXX 2.13c standard and SQL versions are preserved for historical purposes only and receive no active support.

### 2. Before asking for help

- Read the [GunGame manual](docs/readme-gungame.htm), [CSDM documentation](docs/readme-csdm.htm) and [changelog](CHANGELOG.md).
- Search existing Discussions and Issues for related questions and known problems.
- Check the requirements, configuration and compatibility of your installed version.
- Back up your configuration and statistics before making changes.

### 3. Where to get help

General support is provided publicly through [GitHub Discussions](https://github.com/JamesDaRock/GunGame-AMXX/discussions) in English or German.

| Discussion category | Purpose |
| --- | --- |
| Installation & Configuration | Installation, CVARs and server configuration |
| SQL & Database | Statistics, rankings and database configuration |
| Web Interface | PHP rankings and web configuration |
| Compatibility & Integration | Engines, GameDLLs, AMX Mod X, CSDM and other plugins |
| General | General project questions |
| Ideas & Suggestions | Ideas and preliminary feature discussions |

Use [GitHub Issues](https://github.com/JamesDaRock/GunGame-AMXX/issues/new/choose) for reproducible bugs, concrete feature requests, performance problems and other actionable reports. Select the appropriate English or German issue template. See [CONTRIBUTING.md](CONTRIBUTING.md) for reporting and contribution requirements.

### 4. Information to provide

Include the following information where relevant:

- Game (Counter-Strike 1.6 or Condition Zero) and exact GunGame version.
- AMX Mod X, engine and GameDLL versions.
- Statistics backend (local files or MySQL/MariaDB), database version and relevant configuration.
- Relevant plugins, including CSDM and bot plugins where applicable.
- PHP version and web environment for web-related questions.
- Steps to reproduce, expected and actual behavior, and relevant logs or error messages.
- Output of `gg_info` and `gg_status`, where available.
- Troubleshooting steps already performed.

Remove passwords, database credentials, tokens and private information before posting. Do not publish complete configuration files without checking their contents.

### 5. Support scope and availability

Support is voluntary and provided according to availability. No response time, resolution time or individual server installation or remote maintenance is guaranteed.

Support for third-party plugins and components is limited to integration problems relevant to GunGame AMXX 3++. For unrelated problems, contact the respective upstream project or provider.

### 6. Confidential matters

The project contact address is [support@rootutilities.com](mailto:support@rootutilities.com). Email is reserved for confidential matters, not general support requests.

- Report security vulnerabilities privately as described in [SECURITY.md](SECURITY.md).
- Report conduct violations confidentially as described in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Do not disclose sensitive details in public Issues or Discussions. All project-related communication is subject to the [Code of Conduct](CODE_OF_CONDUCT.md).

## Deutsch

### 1. Unterstützte Versionen

Unterstützung wird für die aktuelle Entwicklungsversion von GunGame AMXX 3++ und aktuelle Releases einschließlich des aktuellen Release Candidates angeboten. Die ursprünglichen GunGame-AMXX-Versionen 2.13c Standard und SQL werden ausschließlich zu historischen Zwecken archiviert und erhalten keinen aktiven Support.

### 2. Vor einer Supportanfrage

- Lies das [GunGame-Handbuch](docs/readme-gungame.htm), die [CSDM-Dokumentation](docs/readme-csdm.htm) und den [Changelog](CHANGELOG.md).
- Durchsuche bestehende Discussions und Issues nach ähnlichen Fragen und bekannten Problemen.
- Prüfe die Voraussetzungen, Konfiguration und Kompatibilität deiner installierten Version.
- Sichere deine Konfiguration und Statistiken vor Änderungen.

### 3. Wo du Unterstützung erhältst

Allgemeiner Support erfolgt öffentlich über [GitHub Discussions](https://github.com/JamesDaRock/GunGame-AMXX/discussions) auf Englisch oder Deutsch.

| Discussion-Kategorie | Zweck |
| --- | --- |
| Installation & Configuration | Installation, CVARs und Serverkonfiguration |
| SQL & Database | Statistiken, Ranglisten und Datenbankkonfiguration |
| Web Interface | PHP-Ranglisten und Webkonfiguration |
| Compatibility & Integration | Engines, GameDLLs, AMX Mod X, CSDM und andere Plugins |
| General | Allgemeine Projektfragen |
| Ideas & Suggestions | Ideen und erste Diskussionen über neue Funktionen |

Verwende [GitHub Issues](https://github.com/JamesDaRock/GunGame-AMXX/issues/new/choose) für reproduzierbare Fehler, konkrete Funktionsanfragen, Performanceprobleme und andere konkret bearbeitbare Meldungen. Wähle die passende englische oder deutsche Issue-Vorlage. Die Anforderungen an Meldungen und Beiträge stehen in [CONTRIBUTING.md](CONTRIBUTING.md).

### 4. Benötigte Informationen

Gib, soweit relevant, folgende Informationen an:

- Spiel (Counter-Strike 1.6 oder Condition Zero) und genaue GunGame-Version.
- Versionen von AMX Mod X, Engine und GameDLL.
- Statistik-Backend (lokale Dateien oder MySQL/MariaDB), Datenbankversion und relevante Konfiguration.
- Relevante Plugins, gegebenenfalls einschließlich CSDM und Bot-Plugins.
- PHP-Version und Webumgebung bei Problemen mit dem Webinterface.
- Schritte zur Reproduktion, erwartetes und tatsächliches Verhalten sowie relevante Logs oder Fehlermeldungen.
- Ausgaben von `gg_info` und `gg_status`, sofern verfügbar.
- Bereits durchgeführte Schritte zur Fehlerbehebung.

Entferne vor der Veröffentlichung Passwörter, Datenbankzugangsdaten, Tokens und private Informationen. Veröffentliche keine vollständigen Konfigurationsdateien, ohne deren Inhalt zu prüfen.

### 5. Supportumfang und Verfügbarkeit

Die Unterstützung erfolgt freiwillig nach Verfügbarkeit. Es besteht kein Anspruch auf eine bestimmte Reaktionszeit, Fehlerbehebungsfrist, individuelle Servereinrichtung oder Fernwartung.

Die Unterstützung für Drittanbieter-Plugins und Komponenten beschränkt sich auf Integrationsprobleme, die GunGame AMXX 3++ betreffen. Wende dich bei unabhängigen Problemen an das jeweilige ursprüngliche Projekt oder den Anbieter.

### 6. Vertrauliche Anliegen

Die Projektkontaktadresse lautet [support@rootutilities.com](mailto:support@rootutilities.com). E-Mail ist ausschließlich vertraulichen Anliegen vorbehalten und nicht für allgemeine Supportanfragen vorgesehen.

- Melde Sicherheitslücken vertraulich gemäß [SECURITY.md](SECURITY.md).
- Melde Verstöße gegen die Verhaltensrichtlinien vertraulich gemäß [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Veröffentliche keine vertraulichen Details in öffentlichen Issues oder Discussions. Für die gesamte projektbezogene Kommunikation gelten die [Verhaltensrichtlinien](CODE_OF_CONDUCT.md).
